# go-musthave-diploma-tpl

Шаблон репозитория для индивидуального дипломного проекта курса «Go-разработчик»

# Начало работы

### Запуск скрипта

```bash
# запустить postgres
docker-compose up -d

# отключить postgres
docker-compose down -v
```

### Отключить postgres
```bash
 docker-compose down -v
```
